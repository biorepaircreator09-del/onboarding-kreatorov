# Smart Beauty Hub

Онбординг и рабочий портал для контент-креаторов брендов «Предгорья Белухи» / Smart Bee и Biorepair®.

Статичный: без сборки, без бэкенда, без авторизации. Публикуется на GitHub Pages.

## Как обновить содержание

Весь текст лежит в `content/`. Подробная инструкция для не-программиста открывается
на самом сайте, в разделе «Как обновлять этот сайт» (файл `content/obnovlenie.md`).

Коротко: открыть файл в `content/` на github.com → карандаш ✏️ → поправить →
**Commit changes**. Через 1–2 минуты GitHub Pages опубликует новую версию сам.

| Файл | Что внутри |
|---|---|
| `content/site.json` | меню, порядок страниц, какие из них шаги маршрута, дата обновления |
| `content/*.md` | страницы в Markdown; врезки `> [!ЗАДАНИЕ]`, `> [!ПРЕДПОЛОЖЕНИЕ]` и др., чек-листы `- [ ]` |
| `content/quiz.json` | вопросы теста (`answer` считается с нуля) и практическое задание |

## Как устроено

- `index.html` – оболочка, `styles.css` – оформление (светлая и тёмная тема, телефон),
  `app.js` – движок: читает `site.json`, рендерит Markdown (marked с cdnjs), запоминает
  пройденные шаги, галочки и результат теста в браузере (localStorage).
- Страница бренда получает фирменную полосу по полю `"brand"` в `site.json`.

## Посмотреть локально

```
python -m http.server 8765
```

и открыть http://localhost:8765. Открывать `index.html` двойным кликом нельзя:
браузер не даст прочитать файлы из `content/`.

## Повторная публикация вручную

Если правили файлы не на github.com, а у себя:

```
git add -A
git commit -m "обновил содержание"
git push
```

## Источники

Содержание собрано из бренд-материалов на Яндекс Диске (брендбуки, бриф, портреты ЦА,
описания продуктов, промпт проверки Tone of Voice Biorepair®, регламент группы Smart
Beauty) и публичных соцсетей брендов. Неподтверждённое помечено плашкой «Предположение».

## Иконки

Линейные иконки [Lucide](https://lucide.dev) (лицензия ISC) и иконка зуба из [Tabler Icons](https://tabler.io/icons) (MIT). Встроены прямо в `app.js`, объект `ICONS`. Иконку пункта меню задаёт поле `"icon"` в `content/site.json`.
